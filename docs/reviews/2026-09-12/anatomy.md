# 별 복원·신체 구체화·장기 중심 배치 — 2026-09-12

## 변경

- 별이 사라진 듯 보인 원인: 48개로 감소한 배경 별과 부모 불투명도 0.55, 정적 별 불투명도 0.22가 중첩되어 동작 줄이기에서 실효 불투명도가 0.121이었다. 선택 시에는 더 낮아졌다.
- 배경 별을 96개로 복원하고 정적 밝기·빛 번짐을 보강했다. 음수 애니메이션 지연으로 첫 화면부터 별마다 다른 위상으로 반짝인다. 동작 줄이기에서는 움직임 없이 별을 유지한다.
- 신체 외곽을 다듬고 얼굴·쇄골·손가락·발·골반·척추·팔과 다리 뼈, 뇌 주름·기관지·심장 혈관·간담낭·췌장·콩팥과 요로·장 내부 선화를 추가했다.
- 이름순 부위 격자 대신 질병 slug별 장기 기준점과 주변 배치 구역을 사용한다. 심장/폐, 간/위/장/콩팥, 어깨/손목/척추/고관절/발을 구분한다. 내분비 질환은 대응 높이의 계통 영역을 유지하고 전신 대사 질환을 한 장기에 연결하지 않는다.
- 질병명 공간을 전역으로 확보하고 입력 순서에 관계없이 같은 좌표를 계산한다. 등록되지 않은 질병은 기존 부위 배치를 기준으로 처리한다.
- 선택한 질병에서 해당 장기 기준점으로 점선과 위치명을 표시한다. 노드를 끌면 점선도 따라간다. 모바일 카메라는 선택 질병과 기준점을 함께 담는다.

신체는 탐색용 개략 도판이며, 점 위치는 질환의 정확한 병변·좌우 위치를 의미하지 않는다. DB의 의학 콘텐츠와 관계 데이터는 수정하지 않았다.

## 검증

- 단위 테스트 48개 통과: 새 배치의 전체 시드 매핑, 입력 순서 독립성, 겹침 방지, 주요 부위 구분 및 신규 질병 fallback 포함.
- 타입 검사·린트·프로덕션 빌드 통과.
- 최종 프로덕션 앱에서 브라우저 시나리오 22개 통과.
- 별 가시성 회귀 테스트는 수정 전 실패(실효 불투명도 0.121), 수정 후 통과. 일반 모션에서 반짝임, 동작 줄이기에서 정적 가시성, 장기 표시·전신 질환 예외, 375px 화면의 기준점 가시성 검증.
- 기존 투어·공유·이어보기·모바일 시트·키보드 탐색 시나리오 통과.
- 데스크톱 1440×1000, 모바일 390×844 및 375×812 캡처 확인. 캡처 중 페이지 오류 없음, 375px에서 문서 가로 넘침 없음. Chromium 기준이며 Safari 실기기는 미검증.
